# ReciclaHub

Projeto desenvolvido para a disciplina de Desenvolvimento Web.

## Sobre o Projeto
O **ReciclaHub** é uma aplicação web Full Stack voltada para conectar geradores de resíduos recicláveis a coletores por meio de geolocalização.

## Documentação
A especificação inicial da Etapa 01 pode ser encontrada em [`/docs/proposta.md`](./docs/proposta.md).

## Tecnologias
- **Frontend:** HTML5, CSS3, JavaScript ES6+, Leaflet.js
- **Backend:** Java (Spring Boot)
- **Banco de Dados:** PostgreSQL + PostGIS
